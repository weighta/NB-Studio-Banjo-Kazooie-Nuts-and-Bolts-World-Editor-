   V = [A+0xC3C] (0 on foot). [A+0xC40] = seat block of V; [A+0xCA0]/[A+0xCA4] = vehicle/seat the Y prompt offers;
   [A+0xCBC] = 2 in a vehicle, 0 on foot. Cross-check while seated: [V+0x48] - 0x40 == A (+0x48 = first child link).
   Verified: Y in/out (3 cycles), Change Vehicle (new object), title screen (A = 0, 8 front-end vehicles exist),
   garage (A valid, V = 0), break-up (V keeps the original object with only the seat block; brk1.png).

   vehicle objects with blueprint 0. Freed vehicles (Change Vehicle) keep vtable and blueprint; +0x4C (level) becomes 0,
   the body 0, the block list invalid: alive check = +0x4C != 0 and body pointer unchanged.
